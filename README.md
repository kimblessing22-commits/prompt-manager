# 나만의 프롬프트 관리 프로그램

Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.  
자주 사용하는 프롬프트를 카테고리별로 관리하고, 검색하거나 즐겨찾기에 등록할 수 있습니다.

## 주요 기능

1. 프롬프트 추가
2. 전체 프롬프트 목록 조회
3. 카테고리별 프롬프트 조회
4. 제목 및 내용 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기 목록 조회

## 기본 프롬프트

프로그램 실행 시 다음과 같은 기본 프롬프트 3개를 불러옵니다.

- 비즈니스 미팅 요청 메일 작성 전문 비서
- Red Book 핫핑크 드레스 영상 생성
- 미국 테크 뉴스 자동 기록 워크플로우

## 프롬프트 데이터 구조

프로그램의 여러 프롬프트는 `prompts`라는 리스트에 저장합니다.

리스트 안의 각 프롬프트는 딕셔너리 하나로 표현하며, 다음 네 가지 필드를 가집니다.

- `title`: 프롬프트 제목
- `content`: 프롬프트 본문
- `category`: 프롬프트 카테고리
- `favorite`: 즐겨찾기 여부를 나타내는 Boolean 값

프롬프트 한 개의 구조는 다음과 같습니다.

```python
{
    "title": "프롬프트 제목",
    "content": "프롬프트 내용",
    "category": "카테고리",
    "favorite": False
}
```

## 리스트와 딕셔너리를 선택한 이유

### 리스트

여러 개의 프롬프트를 순서대로 저장하고 반복하여 조회하기 위해 리스트를 선택했습니다.

장점:

- 새로운 프롬프트를 `append()`로 쉽게 추가할 수 있습니다.
- `for` 반복문으로 전체 프롬프트를 쉽게 조회할 수 있습니다.
- 프롬프트가 입력된 순서를 유지할 수 있습니다.

단점:

- 데이터가 많아지면 원하는 프롬프트를 찾기 위해 전체 리스트를 확인해야 합니다.
- 프로그램을 종료하면 메모리에 저장된 변경 사항이 사라집니다.

### 딕셔너리

프롬프트의 제목, 내용, 카테고리, 즐겨찾기 여부를 하나의 데이터로 묶기 위해 딕셔너리를 선택했습니다.

장점:

- `title`, `content`처럼 각 값의 의미가 명확합니다.
- 키 이름을 이용하여 원하는 값을 쉽게 조회하고 변경할 수 있습니다.

단점:

- 모든 프롬프트가 동일한 키 구조를 사용하도록 관리해야 합니다.
- 잘못된 키 이름을 사용하면 오류가 발생할 수 있습니다.

## 데이터 영속화 설계

현재 프로그램은 프롬프트 데이터를 메모리의 리스트에 저장합니다. 따라서 프로그램을 종료하면 실행 중 추가하거나 변경한 데이터가 초기화됩니다.

향후에는 다음 방식으로 데이터를 영구 저장할 수 있습니다.

- 저장 파일 이름: `prompts.json`
- 파일 형식: JSON
- 프로그램 시작 시: `json.load()`를 사용하여 파일의 데이터를 리스트로 불러오기
- 프롬프트 추가 시: 변경된 리스트를 `json.dump()`로 파일에 저장하기
- 즐겨찾기 변경 시: 변경된 즐겨찾기 상태를 JSON 파일에 다시 저장하기
- 프롬프트 수정 시: 수정된 제목, 내용 또는 카테고리를 JSON 파일에 다시 저장하기

예상 JSON 파일 구조는 다음과 같습니다.

```json
[
    {
        "title": "프롬프트 제목",
        "content": "프롬프트 내용",
        "category": "카테고리",
        "favorite": false
    }
]
```

현재 과제에서는 콘솔 기반 핵심 기능과 Git 활용에 집중하였으며, JSON 파일 저장 기능은 향후 확장 기능으로 설계했습니다.
