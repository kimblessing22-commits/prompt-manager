# 나만의 프롬프트 관리 프로그램

Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.  
자주 사용하는 프롬프트를 카테고리별로 관리하고, 검색하거나 즐겨찾기에 등록할 수 있습니다.

## 주요 기능

1. 프롬프트 추가
2. 전체 프롬프트 목록 조회
3. 카테고리별 프롬프트 조회
4. 제목 및 내용 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기 목록 조회

## 기본 프롬프트

프로그램 실행 시 다음과 같은 기본 프롬프트 3개를 불러옵니다.

- 비즈니스 미팅 요청 메일 작성 전문 비서
- Red Book 핫핑크 드레스 영상 생성
- 미국 테크 뉴스 자동 기록 워크플로우

## 실행 방법

### 1. 저장소 복제

```bash
git clone https://github.com/kimblessing22-commits/prompt-manager.git
```
## 요구 환경 및 버전 확인

- Python 3.10 이상
- Git
- 별도의 외부 Python 패키지는 사용하지 않습니다.

설치된 Python 버전은 다음 명령어로 확인할 수 있습니다.

```bash
python --version
```
Git 버전과 사용자 설정은 다음 명령어로 확인할 수 있습니다.
```bash
git --version
git config user.name
git config user.email
```
